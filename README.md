# EDUCATION & COACHING

Международный образовательный проект о самокоучинге, профессиональном развитии педагогов и коучинговом подходе в образовании.

**Слоган:** Развитие человека — развитие образования.

## Сайт
Статическая адаптивная страница на HTML, CSS и JavaScript. Сборка и сторонние библиотеки не требуются.

## Публикация через GitHub Pages
1. Откройте репозиторий **Settings**.
2. В меню выберите **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main** и папку **/ (root)**, затем нажмите **Save**.
5. После публикации адрес сайта появится в этом же разделе Pages.
